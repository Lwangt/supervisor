# UI 规格（参考 Macro7）

## 1. 设计原则

- **一次只面对一件事**：今日页不铺满全部计划，而是突出"现在该做的那一组"（Macro7 的核心设计）。
- **防误触**：整组完成必须**长按 500ms**，单击只展开/收起。
- **深色优先**：默认深色；数字用大字号，一眼可读。
- **零学习成本**：不加自定义手势、不加隐藏菜单。

## 2. 视觉规范

| 元素 | 值 |
|------|-----|
| 背景 | `#101214` |
| 卡片 | `#1A1D21`（比背景亮一档，深色下用抬升而非描边） |
| 圆角 | 卡片 24dp，胶囊 999dp，输入框 16dp |
| 主色 完成 | `#4ADE80` |
| 警示 逾期 | `#F87171` |
| 当前 NOW | `#60A5FA` |
| 次要文字 | `#8A9099` |
| 标题 / 数值 / 正文 | 28sp SemiBold / 40sp Bold / 16sp Regular |
| 间距栅格 | 4 / 8 / 16 / 24 dp |
| 触感 | 长按完成 → `HapticFeedbackType.LongPress` |

## 3. 页面规格

### 3.1 今日（Today）

```
┌──────────────────────────────┐
│ 3月5日 周三            [今天 ▾]│   ← 日期 + 日期选择（可回看/补打卡）
│                              │
│        ╭──────────╮          │
│        │  1240    │          │   ← 进度环（Canvas）
│        │ / 2000   │          │    宏量模式：kcal；否则显示 "3/5 组"
│        │   kcal   │          │
│        ╰──────────╯          │
│   P 96g · C 130g · F 42g     │   ← 宏量明细（无宏量时隐藏）
│                              │
│ ┌──────────────────────────┐ │
│ │ 早餐        [DONE ✓]  8:00│ │   ← 已完成组：绿色 + 打勾
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ 午餐           [NOW] 12:30│ │   ← 当前组：蓝色描边 + 抬升
│ │ ○ 鸡胸肉 150g     210 kcal│ │   ← 条目行，左侧圆形复选框
│ │ ○ 米饭 200g       260 kcal│ │
│ │ ○ 酸奶 1 杯        90 kcal│ │
│ │   ─────────────────────  │ │
│ │   长按完成整组    ▓▓▓▓▓░░ │ │   ← 长按进度指示（500ms）
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ 训练      [UP NEXT] 19:00 │ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
   [今日]  [计划]  [历史]  [设置]
```

**语义标签判定**（`TodayAssembler`）：见 `DATA_MODEL.md` §3。
**长按进度指示**：长按期间卡片底部进度条从左向右填充，满 500ms 触发完成 + 触感；中途松手回弹。

### 3.2 计划（Plan）

列表：按时间排序的组卡片，显示名称、类型图标（🍽/🏋）、时间、重复规则人类可读摘要（"每天"、"工作日"、"每 3 天"、"每月 1,15 日"、"仅一次 3/5"）、条目数、启用开关。
FAB「+ 新建计划」。

**编辑页字段**：
1. 名称（必填，非空校验）
2. 类型：饮食 / 运动（分段控件）
3. 时间：Material3 `TimePicker`（默认 12:00）
4. 提醒：准点 / 提前 10 分钟 / 提前 30 分钟
5. 重复规则：5 选 1 分段控件
   - 每天 → 无附加字段
   - 每 N 天 → 数字输入（≥1）+ 起始日期
   - 每周 → 周一~周日 7 个胶囊（至少选 1，否则阻止保存）
   - 每月 → 1~31 网格多选（至少选 1）
   - 仅一次 → 日期选择
6. 结束日期（可选，默认无）
7. 条目列表：每行 = 名称 + 数量文本 + （饮食）热量/蛋白/碳水/脂肪 + （运动）组数/次数；
   支持增删、上下排序；条目名称必填。

### 3.3 历史（History）

月历网格：7 列，每周一行；单元格着色：

| 状态 | 表现 |
|------|------|
| DONE（当天全部完成） | 主色实心圆 |
| PARTIAL（完成一部分） | 主色 30% 透明度圆环 |
| MISSED（有计划但一项未完成，且已过去） | 红色描边 |
| REST（当天无计划） | 无着色，仅日期数字 |
| FUTURE | 灰色数字，不可点 |
| 今天 | 额外一圈描边 |

点某天 → 底部弹层：该天各组的完成明细 + （若在 `catchUpDays` 范围内）可补勾的复选框。
顶部显示"连续打卡 N 天 · 本月完成率 xx%"。

### 3.4 设置（Settings）

1. **权限状态卡**（最关键）：通知 / 精确闹钟 / 电池优化 三项，未授权显示红色 + 一键跳转按钮
2. **HyperOS 适配引导**：自启动、任务加锁的图文步骤（无法自动跳转，给出截图路径文字说明）
3. 补打卡天数（0/1/2/3）
4. 今日本页显示宏量（开关）
5. 提醒总开关、稍后提醒间隔
6. 导出备份 / 导入备份（SAF 文件选择器，本地文件）
7. 关于：版本、数据存储位置说明、"本应用不联网"声明

## 4. 空状态与边界文案

| 场景 | 文案 |
|------|------|
| 今日无任何计划 | "今天还没有计划" + 按钮「去创建」 |
| 全部完成 | "今天全部完成 🎉"（P2 加撒花动效） |
| 计划列表为空 | "还没有计划，点击 + 创建第一条" |
| 历史无数据 | "还没有打卡记录" |
| 通知权限未授予 | 顶部黄色条："通知权限未开启，到点提醒无法显示" + 「去开启」 |

## 5. 无障碍

- 所有可点区域 ≥ 48dp
- 复选框/开关带 `contentDescription`
- 进度环附带 `semantics { progressBarRangeInfo = ... }`，支持 TalkBack
- 颜色不作为唯一信息载体：语义标签同时有文字（NOW/OVERDUE/DONE）
